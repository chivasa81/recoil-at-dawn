Installing it

  1. Tap Download and wait for it to finish.
  2. Open the file from the notification, or from Files, then Downloads.
  3. Allow the install when Android asks. A newer build installs over an older one and keeps your progress.

If the download seems stuck

  • A bar sitting at 100% can mean it has already finished. Look in Files, then Downloads, for RecoilAtDawn-v0.29.apk before trying again.
  • If you opened this link inside another app, tap Open this page in Chrome above and download from there.
  • If Android warns about an unknown app, tap More details, then Install anyway.

It is a prototype, so things will change and some parts are rough. The game signs in to online leaderboards under the callsign you choose, and the ACCOUNT screen in its settings can turn that off.

Every build is also on the releases page.
