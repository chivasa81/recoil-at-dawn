# Recoil at Dawn

An Iron Daydream Works prototype: a pixel-art run-and-gun for Android phones. One old soldier,
one night, four warlords he trained himself.

This page holds builds to play, not the game's source.

## Play it

On your Android phone, open the **[download page](https://chivasa81.github.io/recoil-at-dawn/)** and tap Download. Every build is also under Releases on the right of this page.

1. Download the `.apk` file.
2. Open it. Android will ask you to allow installs from this source the first time; allow it.
3. Install and play. A newer build installs over the old one and keeps your progress.

It is a prototype: things will change, and some parts are rough. The game signs in to
online leaderboards under the callsign you choose, and the ACCOUNT screen in the settings
can turn that off.
